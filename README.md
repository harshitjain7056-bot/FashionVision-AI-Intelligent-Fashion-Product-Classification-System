# FashionVision AI

### Intelligent Fashion Product Image Classification System

## 📌 Project Overview

**FashionVision AI** is a Deep Learning-based image classification solution designed to automate fashion product categorization for e-commerce businesses.

The system analyzes product images and classifies them into **10 fashion categories**, including T-shirt/Top, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag, and Ankle Boot.

## 🎯 Business Objective

The project demonstrates how Deep Learning can help e-commerce businesses:

* Automate product image classification
* Reduce manual categorization work
* Improve consistency in product listings
* Process large volumes of product images efficiently

## 📊 Dataset

The project uses the **Fashion MNIST dataset**, containing labeled images of common fashion products.

Each image acts as the **input**, while the corresponding fashion category is the expected **output**.

## ⚙️ Methodology

1. Load the Fashion MNIST dataset
2. Explore and visualize product images
3. Normalize pixel values from 0–255 to 0–1
4. Build a simple Artificial Neural Network
5. Train the model using labeled images
6. Evaluate model accuracy
7. Predict product categories for new images

## 🤖 Model Architecture

* **Input:** 28×28 product image
* **Flatten Layer:** Converts the image into a single vector
* **Hidden Layer:** 64 neurons with ReLU activation
* **Output Layer:** 10 neurons with Softmax activation

## 🚀 Business Impact

FashionVision AI demonstrates how AI-powered image classification can support **faster, scalable, and more consistent e-commerce product categorization**, helping businesses streamline product listing and management workflows.
