# FashionVision-AI-Intelligent-Fashion-Product-Classification-System
FashionVision AI is a deep learning-based image classification solution designed to automate fashion product categorization for e-commerce businesses. The system analyzes product images and classifies them into 10 categories, including T-shirt/Top, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag, and Ankle Boot.
